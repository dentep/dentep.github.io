👤 Создание пользователей

Разовая страница: заводит denis и dasha в Firebase Auth и ставит им isAdmin: true.

Сначала в консоли Firebase

  1. Authentication → Get started
  2. Вкладка Sign-in method → Email/Password → Enable → Save
  3. Правила Firestore из trips/firestore.rules опубликуй после создания пользователей — иначе запись профилей будет запрещена

Затем здесь

Кнопка создаст двух пользователей и их профили. Повторный запуск безопасен: существующие пользователи будут пропущены, профили — обновлены.

После этого

  1. Опубликуй правила из trips/firestore.rules (Firestore → Rules → Publish)
  2. Проверь вход на trips/index.html
  3. Удали этот файл — trips/setup_users.html — он больше не нужен
